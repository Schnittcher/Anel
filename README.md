# Anel
   Mit diesem Modul ist es möglich die Anel Produkte in IP-Symcon zu integrieren.

## 1. Voraussetzungen

* mindestens IP-Symcon Version 9.0

## 2. Funktionsumfang

* Anel-Geräte im Netzwerk finden und anlegen
* Relais und IOs schalten, Gerätetemperatur und Sensorwerte anzeigen

Die einzelnen Funktionen sind den Instanzen zu entnehmen.

## 3. Enthaltene Module

* AnelDiscovery
  * Findet Anel-Geräte im Netzwerk und legt AnelHUT-Instanzen an
* AnelHUT
  * Schaltet Relais und IOs und zeigt Gerätetemperatur sowie Sensorwerte an

## 4. Installation
Über den IP-Symcon Module Store.

## 5. Konfiguration in IP-Symcon
Bitte den einzelnen Modulen entnehmen oder die [Dokumentation](https://deinsmarthome.info) aufrufen.
