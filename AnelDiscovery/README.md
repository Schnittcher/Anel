# AnelDiscovery
Mit diesem Konfigurator werden Anel-Geräte im Netzwerk gefunden und als AnelHUT-Instanzen angelegt.

## 1. Konfiguration

Feld | Beschreibung
------------ | ----------------
Benutzername | Benutzername für das Webinterface des Geräts, Standard `admin`
Passwort | Passwort für das Webinterface des Geräts, Standard `anel`

Benutzername und Passwort werden beim Erstellen der Instanzen in deren Konfiguration übernommen.

## 2. Variablen
Keine Variablen vorhanden.

## 3. Funktionen
Keine öffentlichen Funktionen für Skripte vorgesehen. `ANEL_discoverDevices` wird vom Konfigurator selbst aufgerufen.
